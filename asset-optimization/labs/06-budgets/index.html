Lab 06 — Budgets

A budget turns "make it faster" into a number a build can check. The useful budget is not "be under 2.5s" — it is the byte allowance that produces 2.5s on the connection your users actually have, allocated across asset types before anyone writes any code.

Work out the budget for Fast 4G and a 2.5s LCP.

the CLI

$ node budget-check.mjs http://localhost:8080/render/ssr-par/product/3
$ node budget-check.mjs --budget js=120,total=900 https://example.com/
$ node budget-check.mjs --json https://example.com/ | jq '.[0].assets[:5]'

exit code 1 when a budget is exceeded, so it gates a deploy.
