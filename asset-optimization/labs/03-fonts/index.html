Lab 03 — Fonts

A font is a render-blocking dependency discovered three hops in: HTML → CSS → layout decides the font is used → fetch. Everything about font loading is managing the gap between "text exists" and "text is in the right typeface" — and the two failure modes are invisible text (FOIT) and text that jumps (FOUT + metric mismatch).
