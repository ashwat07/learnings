Lab 01 — Detached DOM nodes

A DOM subtree removed from the document is only freed if nothing in JavaScript still points at it. One reference to one node keeps the whole subtree — parents, siblings, children, listeners and all — alive forever. This is the most common leak in single-page apps and the easiest to see once you know where to look.

Open the Memory panel. Take a snapshot, run a leaky cycle 20 times, take another, and filter the class list for Detached.
