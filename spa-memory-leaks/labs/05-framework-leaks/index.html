Lab 05 — Framework leaks

A miniature SPA: a router, three routes, a global store, and components with effects. It leaks in the four ways every real framework app leaks — and none of them are the framework's fault, because all four are references handed to something the framework doesn't own.

The equivalent React code is in the README next to each one.

Navigate a few times by hand, then run 30 auto-navigations in each mode and compare.
