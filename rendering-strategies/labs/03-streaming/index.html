Lab 03 — Streaming

The server does not have to finish thinking before it starts talking. Streaming SSR sends the shell immediately, then flushes each slow section as its data resolves — so TTFB stops being hostage to your slowest query, and the browser can start fetching CSS and JS a second earlier than it otherwise would.

The browser hides chunk boundaries. This lab reads the response as a stream so you can see exactly what arrived when — and curl -N shows the same thing in a terminal.
