Lab 02 — preconnect & DNS

Before a single byte of a resource can move, the browser needs a connection: DNS lookup, TCP handshake, TLS handshake. On a mobile network that is three round trips — often 300–600ms — paid per origin, before the request is even sent. preconnect pays it early, in parallel with something else.

Throttle to Slow 4G in DevTools first. On an unthrottled localhost, connection setup is ~0ms and this entire lab looks pointless — which is itself the lesson about measuring performance on your own machine.

the two pages to compare

  • 01-no-hint.html — a cross-origin script discovered late. The connection is set up when it is needed.
  • 02-preconnect.html — identical, plus one <link rel="preconnect"> in the head.

Hard-reload each with Slow 4G on, and compare when the cross-origin script starts transferring — not when it finishes.

a real third-party origin

Cross-origin timing phases are only visible if the server sends Timing-Allow-Origin. Most CDNs do; many APIs don't.
