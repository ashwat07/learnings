03 — preload traps

Open the console. Then read the waterfall and count how many times each resource was downloaded.

  1. trap-mismatch — preload URL differs from the used URL by one parameter → downloaded twice.
  2. trap-nocors — as="fetch" without crossorigin → downloaded twice.
  3. trap-unused — preloaded, never used → pure waste plus a warning.
  4. trap-no-as — no as → wrong priority, no reuse.
  5. trap-hog — a 900KB high-priority preload of something below the fold, competing with the LCP image for the same pipe.
