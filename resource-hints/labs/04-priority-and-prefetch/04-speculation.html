  • A prerendered page runs its JavaScript before the user has decided to visit. Gate anything with side effects — analytics, A/B assignment, ad impressions, writes — behind document.prerendering === false or the prerenderingchange event.
  • Speculation Rules respect the user's data-saver setting and the browser's own memory pressure heuristics; the browser can and does ignore your rules.
  • Same-origin prerendering is broadly supported; cross-origin prerendering has extra restrictions (and needs opt-in headers).
  • This replaces the old "prefetch on hover" libraries (quicklink, instant.page) with a declarative, browser-scheduled version that also knows about memory and data saver.
