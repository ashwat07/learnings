02 — lazy loading, used correctly and incorrectly

The first image is the LCP element and it is marked loading="lazy" — which is what happens when a team adds lazy loading "to all images" with a codemod. The browser now has to run layout before it will even start the request.

Load this page and note LCP. Then load ?fix=1, which marks the hero eager + fetchpriority="high" and leaves the rest lazy.
