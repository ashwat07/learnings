Lab 05 — Fix the waterfall

One product page with eight independent discovery problems. Your job: get LCP under 1.5s at Fast 4G without removing any resource — same bytes, same content, same third-party origin. Only discovery, priority and blocking may change.

the pages

  • broken.html — the patient. Measure it first, at Fast 4G, three times, and take the median.
  • your-fix.html — an identical copy with a TODO list in the source. Edit this file.

the rules

  • Every resource that loads in broken.html must still load in your fix, with the same server delay and the same byte size. No deleting the tracking script, no shrinking images. (Both would be right in real life; both would also let you skip the lesson.)
  • The visible result must be identical: same hero, same 12 thumbnails, same text, same data rendered.
  • You may add hints, change attributes, move tags, inline things, and change how the JavaScript discovers its data.
