Lab 03 — Structured data

JSON-LD is how you tell a search engine what a page means rather than what it says: this is a product, that number is its price, those stars are an aggregate rating. Get it right and you are eligible for rich results. Get it subtly wrong and you get nothing, silently, with no error anywhere.

The validator below implements the rules that actually cause rejections. Paste your own JSON-LD into it.

Extract the sandbox's JSON-LD, then validate it. Then break it on purpose and see which rules catch what.
