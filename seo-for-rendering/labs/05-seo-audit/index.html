Lab 05 — Audit it

Everything from labs 01–04, as one pass over a list of URLs. The page audits the sandbox; seo-audit.mjs in this folder does the same for any real URL from the command line, and exits non-zero so it can gate a deploy.

Run the audit. Then run the CLI against something real.

the CLI

$ node seo-audit.mjs https://example.com/product/123
$ node seo-audit.mjs --json https://example.com/ | jq '.[0].findings'
$ node seo-audit.mjs $(curl -s https://example.com/sitemap.xml | grep -o 'https://[^<]*' | head -20)

exit code 1 if there are error-level findings — so it gates a deploy.
