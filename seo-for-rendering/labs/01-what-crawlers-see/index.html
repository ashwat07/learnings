Lab 01 — What crawlers see

A crawler that does not run JavaScript sees exactly the bytes your server sent. This lab fetches each rendering mode and extracts what a non-JS consumer would find: the title, the headings, the body text, the links, and the metadata. No opinions — just what is in the response.

This is also how you check a real site: curl -s URL | less. If the content is not in there, it does not exist for most of the web.
