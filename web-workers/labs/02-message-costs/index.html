Lab 02 — Message passing costs

postMessage does not send a reference. It performs a structured clone — a full deep copy, serialised on the sender's thread and deserialised on the receiver's. For a big payload that copy can cost more than the work you moved off the main thread, which is how a worker ends up making things worse.
