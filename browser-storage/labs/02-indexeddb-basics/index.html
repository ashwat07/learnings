Lab 02 — IndexedDB basics

IndexedDB is an object store with indexes and transactions. The API is from 2011 and it shows — but the model underneath is simple and worth knowing precisely, because every wrapper you might use (idb, Dexie, RxDB) is a thin layer over exactly these concepts.

Open Application → IndexedDB in DevTools alongside this page. It does not live-update reliably — refresh the panel after each write.

Create the database, then seed it, then work down the queries.
