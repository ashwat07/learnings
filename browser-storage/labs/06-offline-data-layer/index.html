Lab 06 — An offline data layer

The capstone: reads that never wait for the network, writes that survive a closed tab, a queue that drains in order, and conflicts you resolve on purpose. Reads are implemented; the writes, the outbox and the conflict policy are yours.

The "server" is simulated locally (fake-server.js) so you can make it slow, flaky and conflicted on demand — which is exactly the environment sync code has to survive and exactly what you cannot stage against a real backend.
