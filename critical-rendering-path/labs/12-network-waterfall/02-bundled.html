02 — one bundle

Byte-for-byte (nearly) the same code as page 01, in a single request. Any difference you measure is per-request overhead and connection contention — not payload.

Compare the uncompressed / transferred ratio against page 01's. Compression works better across one large input than fifty small ones; that's a real part of bundling's benefit, and it's easy to forget.
