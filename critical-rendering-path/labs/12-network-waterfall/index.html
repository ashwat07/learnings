Lab 12 — Network waterfall

Same code, four delivery strategies. The interesting comparison isn't 50-vs-1 — it's 50-vs-1 on HTTP/1.1 versus HTTP/2, and both against the import chain.

setup

node make-modules.mjs      # then serve over HTTP
cd ../.. && ./serve.sh     # python3 http.server — HTTP/1.1, 6 connections per origin
  • 01 · 50 separate scripts — watch the 6-wide staircase in the Network waterfall.
  • 02 · one bundle — same code, one request.
  • 03 · a 10-deep import chain — only 10 requests, and possibly the slowest page here. Predict before you measure.
  • 04 · your fix — chunked sensibly, chain flattened, with the caching trade-off measured.

then do the comparison that matters

openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 30 -subj "/CN=localhost"
npx http-server -S -C cert.pem -K key.pem -p 8443      # HTTP/2 over TLS

Enable the Protocol and Connection ID columns in the Network panel (right-click the header row). Then re-run pages 01–03 on both servers and fill in the table in README.md. The h1-vs-h2 delta for page 01 is the headline result of this lab.
