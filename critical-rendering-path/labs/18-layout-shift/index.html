    prose source 4 — the font swap reflows every line

    Typography carries most of the layout shift risk on a text-heavy page, and it is the source people forget because nothing is "loading" in a visible sense. When the web font arrives and its metrics differ from the fallback's, every line box is remeasured: line heights change, wraps move, and everything below this paragraph slides. The fix is not to avoid web fonts — it is to make the fallback occupy the same space, which you can do exactly with metric overrides.
