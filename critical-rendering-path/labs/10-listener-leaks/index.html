Lab 10 — Event listener leaks

1,000 buttons, mounted and unmounted repeatedly, four different ways.

Before you measure: mode 1 attaches a listener to every button and never calls removeEventListener. Nothing else holds a reference to the buttons. Does it leak? Write your answer down — actually write it — then run the measurement. Most people get this wrong, and getting it wrong is the point.

Open the Performance monitor for live Listeners / DOM Nodes / Detached counters, and the Memory tab's Detached elements view after each cycle. In the console, getEventListeners($0) inspects a selected node (Chrome only).
