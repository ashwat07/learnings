Lab 09 — Memory leaks

Six independent leaks. Turn one on, run the three-snapshot drill, find the retainer chain, then fix it in app.js. Open the Performance monitor and watch the shape of the heap line: sawtooth is healthy, staircase is a leak.

performance.memory is coarse and Chromium-only. For real numbers use the Memory tab. Launch Chrome with --js-flags="--expose-gc" to get a gc() function, or press the 🗑 button in the Memory tab to force collection.
