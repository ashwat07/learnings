Lab 02 — Cache first & precaching

Cache-first is the fastest thing a browser can do: no network, no revalidation, no round trip — even offline. It is also permanent staleness by construction, so it is only ever correct for URLs whose bytes cannot change. Everything in this lab is about keeping that invariant while still being able to deploy.

Turn ON "Update on reload" while experimenting, OFF when you want to watch the versions fight.

Register the worker, then reload the page once so it takes control.
