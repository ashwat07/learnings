Lab 01 — Cache-Control basics

Each preset below fetches the same URL three times in a row, then tells you how many of those three actually reached the server. One number, no interpretation needed: 3 means the cache did nothing.

Before you start: DevTools → Network → make sure Disable cache is OFF, or every row will say 3 and you'll learn nothing. Keep the Network panel open with the Size and Priority columns visible.
