Lab 03 — CSRF

There is no bug in the bank. The vulnerability is that the browser attaches your cookies to a request another site caused. The attacker never reads a response and never needs to — causing the write is the whole attack.

The "evil" page below is served from 127.0.0.1:8081, which is a different site from localhost:8080 — so SameSite applies. (Ports don't make a different site; hosts do.)
