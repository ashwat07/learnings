Lab 02 — Microtask starvation

Three ways to keep the CPU busy for 2 seconds. One of them lets the browser paint and handle your clicks. One of them doesn't. One of them can hang the tab so hard you have to kill it. They all look equally "async" in the source.

The bar below is moved by a requestAnimationFrame loop, and the button counts clicks it actually handled. Both are your liveness probes — mash the button while each run is in flight.

Run A through E. Then read the numbers, not the code.
