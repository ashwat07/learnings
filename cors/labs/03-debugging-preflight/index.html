Lab 03 — Debug a preflight failure

Eight broken CORS configurations. For each one: run it, read the console error, look at the raw OPTIONS exchange, and write down the diagnosis before you reveal it. Aim to name the missing or wrong header from the error message alone.

The workflow that matters here is the one you will use at work: error message → Network panel → raw OPTIONS → the one header that is wrong. The "probe" button is a curl -X OPTIONS that runs on the server, because CORS deliberately hides the failing response from JavaScript.

Keep the DevTools console open — the real message only appears there.
