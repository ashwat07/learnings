Lab 06 — Build a CORS diagnoser

Everything from labs 01–05, as one tool. Configure a server's CORS policy on the left; the simulator runs ten different requests against it using the Fetch spec's algorithm and tells you exactly what a browser would do, including the error text. Then it audits your config for the security mistakes that actually get exploited.

This is the deliverable to keep: a config you can defend, and a tool that explains why.
