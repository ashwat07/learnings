Lab 02 — Simple vs preflighted requests

Some cross-origin requests go straight out. Others are preceded by an OPTIONS asking permission. The rule is not "reads vs writes" and it is not "GET vs POST" — it is a specific safelist, and the reason for it is historical: a preflight is required exactly when the request could not have been made by an HTML form before CORS existed.

Build a request below, predict whether it preflights, then send it. The verdict is measured from the server's own OPTIONS counter, not guessed.
