Lab 04 — Resumability

Hydration re-executes your components on the client so the framework can discover which element has which handler. Resumability skips that entirely: the server already knew, so it writes the answer into the HTML — which handler, from which module, with which state. The client ships one small listener and runs no component code at all until an event happens.

Read resume.js first. It is 30 lines, and once you have read it the idea stops sounding magical.
