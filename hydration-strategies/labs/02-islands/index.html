Lab 02 — Islands

Static by default, interactive by exception. The page below is server-shaped HTML with three islands in it. Each island's JavaScript is a separate module, loaded only when that island is actually hydrated — so "JS shipped" becomes a per-island decision you can measure instead of a whole-bundle number you can only regret.
